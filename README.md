# Flask Chatbot

A simple rule-based chatbot built with Python and Flask.

## About

This project is a small web application where users can interact with a chatbot through a browser.

The chatbot uses predefined rules to recognize common messages and return responses.

## Features

- Simple web-based chat interface
- Flask backend
- Rule-based responses
- JavaScript-based message handling
- JSON API responses

## Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
